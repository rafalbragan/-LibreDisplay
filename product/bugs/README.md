# LibreCare Canonical Bugs

Canonical bug records are stored as `BUG-XXXX.json`.

Rules:
- Use this directory only for deterministic bug records.
- `CONFIRMED_DEFECT` can be auto-routed to a Copilot fix issue.
- `NEEDS_PRODUCT_DECISION` must be routed to Product Inbox human review.
- Never auto-merge bug-fix pull requests.
