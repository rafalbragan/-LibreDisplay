# LibreCare — materiały Google Play (PL)

## Nazwa
LibreCare

## Krótki opis
Historia glikemii, import LibreView CSV i interaktywne wykresy.

## Pełny opis
LibreCare pomaga przeglądać historię pomiarów glukozy na telefonie. Aplikacja udostępnia połączenie z LibreLinkUp oraz lokalną historię, dostępną również bez aktywnej sesji sieciowej.

**Import historii LibreView**
Wybierz eksport CSV przez systemowy selektor plików albo wskaż folder. Lista folderu pokazuje wyłącznie pliki ze zweryfikowanym nagłówkiem LibreView. Przed zapisem wybierasz osobę lub osobny profil lokalny, sprawdzasz daty, strefę czasową, liczbę pomiarów, duplikaty i konflikty, a następnie potwierdzasz nazwę profilu.

Import obejmuje pomiary historyczne i skany w mg/dL. Inne zdarzenia nie są traktowane jako glukoza. Istniejące wartości nie są nadpisywane przez import. Ponowny import tego samego pliku nie tworzy kolejnych kopii pomiarów. Zaimportowana historia nie jest usuwana przez rutynową automatyczną retencję; można ją usunąć świadomie w ustawieniach prywatności.

**Interaktywna historia**
Przeglądaj dzień, tydzień, miesiąc, rok lub cały dostępny okres. Przybliżaj wykres gestem dwóch palców, przesuwaj go poziomo i dotykaj, aby odczytać rzeczywistą wartość oraz czas pomiaru. Długie przerwy w danych nie są łączone linią. Widok historyczny jest wyraźnie oznaczony i nie potwierdza bieżącego połączenia z czujnikiem.

**Kontrola danych**
Dane poszczególnych osób pozostają rozdzielone. Aplikacja oferuje lokalne statystyki, ustawienia przechowywania, kopie danych i funkcje prywatności. Tryb DEMO służy poznaniu interfejsu na danych syntetycznych.

LibreCare nie wylicza dawek insuliny, nie zaleca leczenia i nie zastępuje porady lekarskiej ani wskazań urządzenia pomiarowego. Nie należy opierać decyzji terapeutycznych wyłącznie na aplikacji. Dostępność danych sieciowych zależy od zewnętrznej usługi i ważności sesji.

LibreCare jest niezależną aplikacją. Nazwy LibreView i LibreLinkUp identyfikują obsługiwany format oraz usługę; nie oznaczają powiązania ani zatwierdzenia przez Abbott.
